# AgendaFácil

Sistema de gerenciamento de atendimentos para uma clínica médica de pequeno porte, refatorado seguindo rigorosos padrões de qualidade interna, modularização, documentação e programação defensiva.

## Requisitos
* Python 3.10 ou superior
* Biblioteca `pdoc` (opcional, para geração da documentação de API)

## Como Compilar e Executar
Para executar o programa de demonstração, utilize o comando:
```bash
python3 agenda.py
